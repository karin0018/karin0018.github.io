# Rui Lv’s academic homepage

Built with AcademicPages (Minimal Mistakes).
Theme license: MIT, see LICENSE.

Edit `index.html` for homepage content, `_config.yml` for profile details,
and `_data/navigation.yml` for navigation. GitHub Pages builds the Jekyll site.

## Writing a blog post

Copy `docs/post-template.md` into `_posts/YYYY-MM-DD-short-title.md`.
Update the title, date, excerpt and tags, then write the Markdown body.
Push to `master` to publish at `/blog/short-title/`; the blog list updates automatically.
Put article images in `images/posts/` and link them with `/images/posts/filename.png`.
For unpublished work, use `_drafts/` or set `published: false` in front matter.
Future-dated posts stay unpublished until a build runs after their date.
